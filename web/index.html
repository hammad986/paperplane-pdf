Paperplane Legal & Privacy Center

Official Policy

Data Privacy & 24-Hour Ephemeral Storage

Uploaded documents are processed in temporary directories and automatically deleted within 24 hours. When Client Privacy Mode (WASM) is enabled, processing takes place entirely inside your browser sandbox.

1. Information We Collect

Paperplane PDF operates under data-minimization practices. We collect only information required to execute user-requested document tasks:

  • Account Credentials: When signing in with email or Google OAuth, we store your email address, verification status, and an encrypted session token. Passwords are salted and hashed with PBKDF2 (210,000 iterations).
  • Document Ephemeral Data: Uploaded files are placed in isolated temporary directories on the server. Files are retained for up to 24 hours to allow user downloads, after which an automated cleanup daemon permanently unlinks them.
  • Usage Counters: Daily operation counts are tracked per account or IP address to enforce fair use limits and prevent denial-of-service abuse.

2. How Files and Data Are Handled

  • No Artificial Intelligence Training: Your uploaded documents, text contents, and OCR outputs are never used to train, retrain, or improve public machine-learning models.
  • Automated 24-Hour Purge: A server-side cleanup task automatically deletes job directories and temporary files whose age exceeds 24 hours.
  • Third-Party Processors: Payment processing is handled by Cashfree Payment Gateway. Sign-in authentication may use Google Identity Services. We do not sell user data to advertising brokers.

3. Security Architecture

All traffic is encrypted in transit using TLS 1.3 / HTTPS. We enforce security headers including Content-Security-Policy, X-Content-Type-Options: nosniff, X-Frame-Options: SAMEORIGIN, and Referrer-Policy. Documents are processed in isolated in-memory sandboxes and permanently purged from server memory and disk upon completion or within 24 hours.

4. User Rights and Data Deletion

You may request deletion of your account and associated session records at any time. For privacy inquiries or deletion requests, contact support@paperplane.qd.je.

import fs from 'node:fs';
import { Blob } from 'node:buffer';

const API_BASE = 'https://paperplane.qd.je/api/v1';
const API_KEY = process.env.PAPERPLANE_API_KEY || 'YOUR_PAPERPLANE_API_KEY';
const HEADERS = { 'Authorization': `Bearer ${API_KEY}` };

async function mergePdfs(pdfPaths) {
  const form = new FormData();
  form.append('operation', 'merge');
  
  for (const p of pdfPaths) {
    const fileBytes = fs.readFileSync(p);
    form.append('files', new Blob([fileBytes], { type: 'application/pdf' }), p);
  }

  // 1. Submit merge job
  const res = await fetch(`${API_BASE}/jobs`, {
    method: 'POST',
    headers: { ...HEADERS, 'Idempotency-Key': `merge_${Date.now()}` },
    body: form,
  });
  if (!res.ok) throw new Error(`API error: ${res.statusText}`);
  const { job_id } = await res.json();
  console.log(`Merge job dispatched: ${job_id}`);

  // 2. Poll job status
  while (true) {
    const poll = await fetch(`${API_BASE}/jobs/${job_id}`, { headers: HEADERS });
    const info = await poll.json();
    if (info.status === 'completed') break;
    if (info.status === 'failed') throw new Error(info.error);
    await new Promise(r => setTimeout(r, 500));
  }

  // 3. Download output
  const dl = await fetch(`${API_BASE}/jobs/${job_id}/download`, { headers: HEADERS });
  const buffer = Buffer.from(await dl.arrayBuffer());
  fs.writeFileSync('merged_document.pdf', buffer);
  console.log('Merged PDF saved to merged_document.pdf');
}

mergePdfs(['invoice_p1.pdf', 'invoice_p2.pdf']);
// In-Browser direct REST invocation
async function convertFileInBrowser(file, operation = 'compress') {
  const API_KEY = 'YOUR_PAPERPLANE_API_KEY';
  const form = new FormData();
  form.append('operation', operation);
  form.append('files', file);

  const res = await fetch('/api/v1/jobs', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`
    },
    body: form
  });

  if (!res.ok) {
    const err = await res.json();
    throw new Error(err.detail?.message || err.detail || 'Submission failed');
  }

  const { job_id } = await res.json();
  
  // Poll status
  let done = false;
  while (!done) {
    const statusRes = await fetch(`/api/v1/jobs/${job_id}`, {
      headers: { 'Authorization': `Bearer ${API_KEY}` }
    });
    const data = await statusRes.json();
    if (data.status === 'completed') {
      window.location.href = `/api/v1/jobs/${job_id}/download`;
      done = true;
    } else if (data.status === 'failed') {
      throw new Error(data.error);
    }
    await new Promise(r => setTimeout(r, 500));
  }
}
